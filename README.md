# Morse Code Translator (Eye Blink & Hand Gesture)

Translate Morse code using eye blinks or thumb-index finger gestures through your webcam.

## Features
- Eye mode: blink to type Morse code
- Hand mode: pinch or spread your fingers to type Morse code
- Live on-screen feedback and decoded text
- Start/Stop, Switch Mode, Clear, and Erase buttons

## Install
pip install -r requirements.txt

## Run
python eye.py

## How to use
- Eye mode: short blink = dot, long blink = dash
- Hand mode: pinch fingers together = dot, spread them apart = dash
- Pause for about 2 seconds to finish a letter
- Press ESC to quit

## Requirements
- Python 3.8+
- A webcam
